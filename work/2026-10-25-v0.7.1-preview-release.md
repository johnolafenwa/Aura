# Aura 0.7.1 Preview Release

## Goal

Release Aura 0.7.1 as a technical preview with the fixes merged since
0.7.0, as John asked on 2026-10-25: the AuraDB regression fixes (PRs #139
and #142) and the 0.7.0 security review and bug hunt fixes (PRs #140 and
#141).

## Cutoff

The candidate is cut from `main` at `1f5c1374`, the merge of PR #142.

## Work Completed

- Bumped the CLI, compiler, core, runtime, root package, language server,
  and VS Code extension to 0.7.1. The semantic interface stays 20, and the
  native cache format stays `v10`.
- Updated `Cargo.lock` with `cargo update --workspace`, the path crates in
  `fuzz/Cargo.lock`, and `package-lock.json` with
  `npm install --package-lock-only`.
- Pointed the installer, release workflow example, install guides, Manual
  stamp, docs release metadata, CLI README, release process page, and
  tutorial 01 at `v0.7.1-preview`. Regenerated `llms.txt` and
  `llms-full.txt`.
- The performance page and the Batch 7 checkpoint keep their 0.7.0
  measurements, which describe that release.
- Moved the Unreleased CHANGELOG entries into the 0.7.1 and extension 0.7.1
  sections. The extension section takes the language server entry. The
  0.7.1 section groups the rest under security, fixes, and performance.

## Verification

- Local: release metadata and packaging, identity, docs release metadata,
  language server, extension check and tests, documentation examples,
  `docs:llms:check`, and hygiene.
- Hosted CI runs on the release PR.

## Release

- Remaining: green hosted CI on the release PR, merge, and the annotated
  `v0.7.1-preview` tag on the merge commit after John approves. The tag is
  unsigned by choice because no repository signing identity is configured.
