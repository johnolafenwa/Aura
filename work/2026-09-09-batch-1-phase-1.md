### Daybreak Blue regression preparation

The read-only `phase1_security_regressions` sub-agent identified deterministic
seams for the required security-sensitive tests; it changed no files and ran
no builds or resource loads. These are planned tests, not completed coverage:

- Semantic interface schema 6 and native-cache format v6 currently participate
  in the CLI cache key. Pin each new schema/layout identity independently.
- Serialized MIR currently has no version envelope; extend its shared validator
  before accepting new union/callable metadata, with tiny mutate-after-lowering
  tests for invalid canonical members, tag maps, layouts and ownership plans.
- Test generic substitution/normalization using small nested and duplicate
  member sets, with one canonical producer and validator.
- Extend structural Transfer admission with precise forbidden capture paths,
  and reject asserted TaskCallable metadata lacking concrete evidence.
- Use deterministic allocation budgets for overflow/over-alignment, prefix
  initialization failure and reverse cleanup; never rely on host exhaustion.
- Preserve the cache's existing digest, symlink, executable-shape and
  concurrent-replacement protections. Reuse those small test seams.
