### Container callable identity closure (2026-09-10)

The audit finding: for a runtime-selected list, dictionary, or set element
whose payload nests a callable, `rebase_callable_rvalue` discarded the
callable's descendant path, so `entry[0](value)` after `callbacks.get(index)`
had no authoritative identity and the forged declared type was trusted. The
existing constant-index regression missed it. The fix and the further gaps
found while closing it:

- `rebase_container_result_callables` preserves every descendant suffix,
  merges the identities of every possible element (equal identities stay
  exact; distinct functions sharing one contract keep the contract without a
  name; differing contracts poison the suffix as `Unknown`), and poisons any
  suffix that some possible element lacks. `keys`/`values`/`items` results
  record element identities under the `__any_element` wildcard; dictionary
  `__index` reads now consult `__map_value_` entries.
- Container mutation (`append`, `insert`, `extend`, `set`, `__set_index`,
  `add`, `setdefault`, `update`, `pop`, `remove`, `sort`, `reverse`, ...)
  collapses exact element identities into merged wildcard identities and
  clears them when an inserted operand carries no identity.
- Returned callables are validated against the declared return contract;
  call results and parameters receive identities derived structurally from
  their declared contracts (tuples, class fields, enum payloads, optionals,
  container elements), so boundary-checked declared contracts are
  authoritative inside a function and forged local metadata for derived
  places is never trusted. Callable contract matching now uses
  `type_pattern_matches` over the destination's type parameters.
- The merge rule also repairs an over-strict rejection: a list holding two
  distinct functions with one contract, selected at runtime, was rejected on
  both backends before this change.

Regressions in the uncommitted type-pattern work, confirmed absent at commit
`3f9f95a` and repaired here: ordinary method-call results inherited their

### Narrowing and flow (2026-09-10)

The narrowing family implements ADR-0052 A3/A4 as refinement facts on the
checker's existing place model. A `LocalBinding` carries facts keyed by
projection path (root local or parameter, fixed field, tuple position, or
view); `value is None` and `value is not None` partition the declared
members, `not` swaps the successors, `and`/`or` check their right operand
under the left operand's facts and combine short-circuit edges, and
parentheses pass through. `if`/`elif`, `while`, and conditional expressions
apply the selected facts to their branch, a branch that diverges with
`return`, `break`, or `continue` contributes nothing to the join, and a join
keeps a fact only when every reachable path carries it (union of members).
A `while` body is checked twice so a fact entering the loop survives only when
no iteration can kill it. Facts end at assignment to the place or an
ancestor, `match mut`, calls with `mut` arguments, builtin mutable arguments
and mutating receivers; the stale fact is remembered and a later member use
reports AU2014 with the test and invalidation spans. Writes through the
narrowed payload (`local += 1`) and proven-disjoint sibling fields keep the
fact. A single remaining member becomes the effective type of the place and
is recorded by span in a `NarrowedRead` side table (mirroring union
injections) that the lowering and the analysis pass read; a larger remaining
set only sharpens `match` coverage through `narrowed_scrutinee_type`.
Equality with `None` never narrows, and a test on a non-union place or a
temporary evaluates once and attaches no fact.

`UnionTagTest` plus `Branch`, with `cond_and`/`cond_or` chain blocks, so the
shared validator's tag proofs reach the selected successor; narrowed reads
lower to the payload projection (view roots through `Reborrow` and
`ReadLoan`), owned non-Copy reads use `UnionTakePayload` and consume the whole
union, Copy members copy, and compound assignment writes through the payload
projection. The validator infers the complementary member on the else edge
of a two-member union and keeps a tag proof across writes inside the proven
payload. Two defects were found by probing beyond the planned fixtures and

printed `false` for a `None` value (now a tag test on both backends), and

expressions initially did not narrow; the three checker arms now apply the
condition's facts and the result hint types each arm under its own locals.

`Type` is unchanged (the runtime relies on it); the complete contract is
compared by `callable_slot_admission` / `check_callable_positions` in
`sema/callables.rs`, and rendering shows names, `*`, and `= ...`.

Interpretation recorded for the user: a *written* destination contract
(annotation, parameter, field, element type, alias, return type) is the
explicit restriction the checkpoint requires, so it admits a value whose
contract it can hide (names), weaken (default availability), or restrict
(a named positional-or-keyword slot to keyword-only) and rejects a rename,
an invented default, a keyword-only slot made positional, or any type,
mode, or result difference (`AU2015`). *Inferred* contexts never invent a
common contract: rebinding must satisfy the local's current contract, a
conditional or match join without an expected type needs identical
contracts, a container literal's element contract is its annotation or its
first element's contract and every later element or insertion must satisfy
it, and repeated generic evidence must be admitted by its first
observation. The explicit adapter is a non-generic thin alias called with
one function value or capture-free lambda (`Unary(increment)`); it lowers to
the value in a temporary carrying the alias contract, and a capturing
closure is refused with a pointer to the coming `Callable[...]` storage.
This keeps the maintained surface (a named function passed to a
`def(int32) -> int32` parameter) valid while removing every silent erasure
Codex had implemented: `default_erased`, `erase_type_callable_contracts`,
and `merge_type_callable_contracts` are gone, mutable storage keeps its
written or inferred contract (sound because every insertion is checked),
and the retired `AU2003` "contract was erased" diagnostics became `AU2004`
positional-only and `AU2015` contract errors. Lambdas must use the expected
contract's names and boundary and cannot promise a default (`AU2015`);
builtin callback contexts still supply positional types only.

The MIR gains `MirParam.keyword_only`; the validator's contract check uses
admission (a boundary may hide or weaken, never rename, invent, or expose a
keyword-only slot positionally), the function-operand check treats the
operand's declared contract as the destination the declaration must satisfy,
and closure declarations must keep their boundary. The semantic interface
schema is 12 (`FunctionParamContract` lost `default_erased`).

### Callable packing and call kinds (2026-09-11)

Q13 A, Q14 A, Q15 A, Q16 A, and the packing half of Q21 A. Both backends
already represent a closure as a boxed function value whose environment
holds its captures, so the owned callable storage types are a compile-time
erasure over that value: `Type::Callable` carries `task`, the call kind,
and the complete contract with the capture set erased, is non-Copy and
non-cloneable, has no equality, and is Transfer only as `TaskCallable`.
Written `Callable[def(...)]`, `Callable[mut def(...)]`,
`Callable[own def(...)]`, and `TaskCallable[...]` lower to it in the
checker, the lowering's and analysis's infallible helpers, and the builtin
module loader; the parser family's staging guard is gone.

Packing is explicit (C1, C5): calling a non-generic alias of an owned
callable type with one function value, lambda, closure, or already packed
value packs it. The value's complete contract must be admitted, its call
kind may only weaken (Shared into Mutable or Consuming, Mutable into
Consuming; the reverse is `AU2015`), a closure or function reaching a
`Callable` destination without the constructor is `AU2015` implicit erased
storage, a loan capture cannot be packed (`AU3010`), and `TaskCallable`
packing proves every capture Transfer (`AU3008`, naming the capture). The
lowering moves the value into a temporary carrying the alias type; no
second environment is allocated, which is recorded as the substitution for
the checkpoint's inline-buffer and allocation-counter evidence. Calls go
through the contract: Shared through any access, Mutable through a mutable
place (`AU3003`), Consuming once by an owner; a callable field is called
with method syntax, and a list or dictionary element through a call-scoped
shared read (a Consuming element must be removed first). Packed values
store in parameters, results, fields, list and dictionary elements, and
cross modules through public aliases; branches merge only through an
explicit common `Callable` contract.

Owned-capture mutation (C2): a lambda body may call a `mut` operation on an
owned capture; the checker records the capture as mutated, the closure
becomes Mutable, the closure function takes that capture mutably, the
interpreter writes the updated value back into the environment, and the
direct runtime already did. A shared-view capture stays read-only. The MIR
closure rvalue now records the Mutable kind so the validator's identity is
authoritative; the validator admits an erased destination whose kind is no
weaker than the value's, checks erased destinations for top-level arguments
(which the previous early return skipped, caught by the new security
binary), treats disagreeing identities under one erased element type as
that contract, and checks erased boundaries at calls, task starts, call
results, and function operands. The semantic interface schema is 13.
