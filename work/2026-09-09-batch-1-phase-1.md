### Container callable identity closure (2026-09-10)

### Narrowing and flow (2026-09-10)

The narrowing family implements ADR-0052 A3/A4 as refinement facts on the
checker's existing place model. A `LocalBinding` carries facts keyed by
projection path (root local or parameter, fixed field, tuple position, or
view); `value is None` and `value is not None` partition the declared
members, `not` swaps the successors, `and`/`or` check their right operand
under the left operand's facts and combine short-circuit edges, and
parentheses pass through. `if`/`elif`, `while`, and conditional expressions
apply the selected facts to their branch, a branch that diverges with
`return`, `break`, or `continue` contributes nothing to the join, and a join
keeps a fact only when every reachable path carries it (union of members).
A `while` body is checked twice so a fact entering the loop survives only when
no iteration can kill it. Facts end at assignment to the place or an
ancestor, `match mut`, calls with `mut` arguments, builtin mutable arguments
and mutating receivers; the stale fact is remembered and a later member use
reports AU2014 with the test and invalidation spans. Writes through the
narrowed payload (`local += 1`) and proven-disjoint sibling fields keep the
fact. A single remaining member becomes the effective type of the place and
is recorded by span in a `NarrowedRead` side table (mirroring union
injections) that the lowering and the analysis pass read; a larger remaining
set only sharpens `match` coverage through `narrowed_scrutinee_type`.
Equality with `None` never narrows, and a test on a non-union place or a
temporary evaluates once and attaches no fact.

union, Copy members copy, and compound assignment writes through the payload

### Union properties (2026-09-10)

Probes before implementation showed that union equality was always `false`
(the shared `PartialEq for Value` had no union arm, so dictionary and set
keys of union type could never be found), that every union was classified
as non-Copy and non-Transfer, that `.clone()` and trait method calls on
union receivers were rejected, and that ordering on a union reported the
generic AU2999. The checker's member injection for `==`, with AU2010 for
nonmembers and AU2011 for ambiguous literals, already existed.

Equality (Q6 B) is active-member equality in `union_runtime::union_values_equal`,
reached from the shared `PartialEq` so both backends and the collection key
lookups agree; a bare member compares by the same rule, which is the
comparison-only injection without a runtime box, and a symbolic-layout value
from a generic frame compares by its active member. Keys of union type
therefore hash as their active member. Copy, symbolic copy, and Transfer
fold over every member; `.clone()` on a union is admitted when every member
is Copy or clones itself and clones the active payload on both paths. A

### Review findings held for ratification (2026-09-13)

Three findings of the independent review are deviations from the ratified
checkpoint that the implementation documented as delivered scope rather
than implementation defects, and they are held for an explicit decision
instead of being changed unilaterally:

- **Finding 10, written destinations restrict contracts (C5 / Q17 A).**
  `step: Unary = increment` currently reinterprets the written destination
  as an explicit restriction of the value's contract (drops the name and
  default availability) and is pinned by tests and the functions chapter.
  Checkpoint C5 calls a differing bare assignment an error and requires the
  explicit adapter `Unary(increment)`. Options: implement the ratified rule
  (a source-incompatible tightening for programs that rely on the implicit
  restriction) or amend C5 to admit the implicit restriction. The tests and
  the functions chapter change either way.
- **Finding 11, physical union and callable storage (Q9 / Q15 / Q16).**
  Union injection boxes its payload and closure construction allocates an
  `Arc` environment; the ratified answers require no mandatory per-union
  allocation, inline fitting environments with checked overflow, and a
  shared operations table, and exclude an always-allocated environment as an
  alternative. The boxed stand-in is disclosed in the backend boundary, the
  closures chapter, and the phase record, but disclosure is not delivery.
  This is a representation project with allocation measurements, not a fix;
  it needs a scheduling decision (a phase 1 follow-up before H2, or an
  amendment recording the stand-in as the accepted representation).
- **Finding 12, editor support (H1 tooling).** The language server still
  lacks signature help, rename, and reference handlers. Alias resolution,
  `Callable` call inference, and the extension grammar rules for aliases,
  contextual `is`, `|`, and `Callable` are fixed in this follow-up. The
  missing protocol handlers remain held for implementation before H2 or an
  explicit amendment narrowing H1 tooling scope.
