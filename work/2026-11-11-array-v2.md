# Array v2

Date: 2026-11-11. Asked for by John: "Go ahead and make sure the work is
done until 4 is complete, we can make decision on tensors and device
interop later". The four items:

1. Views and shape operations: strided views, `reshape`, `transpose`,
   multidimensional and step slicing, slice assignment.
2. Broadcasting between shapes, axis reductions, comparisons,
   elementwise math, element type conversion.
3. Matrix products beyond two dimensions. The speed of the `matmul` and
   `dot` kernels belongs to the SIMD work.
4. Zero-copy transport: Arrays to foreign functions, `simd` lane loads
   from an Array, sharing an Array across tasks, fast multidimensional
   element reads.

Tensor and device interop is deferred and not started.

## Item 1: views and shape operations

Design record: ADR-0088.

The decision that shapes everything else: a view is not a borrow. An
Array stays an owned value. Its element buffer is reference counted, and
a write copies the buffer first when another Array still reads it. No
borrow rule changed, and a slice is an ordinary `Array[T]`.

What works, on both backends:

- **Selections.** An index takes a coordinate or a slice per axis, with
  steps: `m[1, :]`, `m[:, 2]`, `m[::2, 1:3]`, `m[::-1]`. An index with a
  slice has type `Array[T]`.
- **Shape members.** `reshape` with one `-1` dimension, `flatten`,
  `transpose`, `permute`.
- **Slice assignment.** `m[sel] = value` and `m[sel] op= value` with a
  scalar or an Array that broadcasts to the selection. The value may
  read the target, and the target is written in place when the value was
  the only other reader.
- **Shared storage.** `clone()`, selections, and shape members copy no
  element when the result is one row-major block. `clone()` of a partial
  view copies only the view.

Where the code is:

- `crates/aura-runtime/src/array_layout.rs`: `ArrayBuf`, a window of a
  shared buffer, and the strided walkers `walk_runs`, `gather`,
  `scatter`, and the broadcast helpers item 2 will use.
- `crates/aura-runtime/src/array_views.rs`: selection words, `select`,
  `reshape`, `permute`, `transpose`, `assign`, `assign_owned`.
- `crates/aura-runtime/src/runtime_value.rs`: `ArrayValue` holds a base
  storage and optional strides. `elements()` gives row-major elements,
  packing a strided view.
- Parser: `parse_index_component`. A slice inside an index is a call of
  the hidden `%slice` builtin with an omitted object. A lone slice in an
  expression keeps the older `Slice` node.
- MIR: private members `__select_words` and `__assign_words` for one or
  two index components, whose selection words are plain `int64`
  arguments, and `__select` and `__assign` for three or more, whose
  words travel in a tuple. `ArrayOp::SelectWords`, `AssignWords`,
  `Select`, `Assign`, `Reshape`, `Flatten`, `Transpose`, `Permute`.
- Native runtime entries: `aura_direct_array_select_words`,
  `aura_direct_array_assign_words_in_place`, `aura_direct_array_select`,
  `aura_direct_array_assign_in_place`, `aura_direct_array_reshape`,
  `aura_direct_array_relayout`.

Speed work, in the order it mattered:

- The selection words of a one or two component index are passed as
  plain arguments. A tuple of words cost about 16,000 instructions per
  view.
- `select` works out its layout in `AxisVec`, which keeps up to six
  axes inline, so a view of a matrix allocates only its shape.
- `gather` reserves once per run. A push per element made a column read
  cost about 2 ns per element.
- Assignment owns its value. A block of the target moves inside the
  buffer (`ArrayBuf::copy_within_from`), and a block written over a
  block is one `copy_from_slice`.
- `clone()` of a partial view copies the view, so a kept row does not
  make the next write copy the matrix.

Decisions made along the way:

- `m[0]` on a matrix stays a rank trap. The static type of an index of
  coordinates is the element type, because rank is a run-time fact.
- Slice bounds follow the list rules: no clamping, `AU4003`.
- Slice assignment on a list or `str` stays `AU2005`.
- The formatter writes `m[1, :]`, keeping the space after the comma.
- Arrays are still not iterable with `for`.

## Follow-up

- Items 2, 3, and 4.
- An elementwise operation, a reduction, or a product over a strided
  view first copies the view into row-major order. Item 2's broadcast
  walk replaces that copy for elementwise operations.
- Four benchmark loops are behind NumPy because of temporaries:
  `transposed_add`, `stencil`, `column_scale`, `reshape_reverse`. Item 2
  owns the fix: strided walks, reuse of a temporary operand, and an
  in-place `m[selection] op= value`.
- `row_swaps` is 4.9 times Rust's `swap_with_slice`. About 1,000
  instructions per runtime call remain around each view.
- A slice assignment to an immutable list now reports `AU2005` before
  `AU3003`, as it did when the parser refused it.

## Item 2: broadcasting, axis reductions, elementwise members, masks

Decision record: ADR-0089.

- Runtime: `array_elementwise.rs` walks two operands over a broadcast
  shape in runs, so a contiguous run still reaches the SIMD kernels.
  `array_reduce.rs` reduces one lane at a time with the whole-Array
  kernels, which keeps the bits equal to a reduction of the lane's view.
  `array_members.rs` holds the elementwise members, casts, comparisons,
  and masks. `ArrayStorage::Bool` is the fifth storage kind.
- `a[selection] op= value` lowers to one `__update_words` call for one or
  two index components. Float elements are updated where they lie, in
  blocks of 16 for a strided target so a write lands on the cache line
  its read loaded. A zero divisor is found before any element is written.
- A temporary read once by the next arithmetic step lends its buffer.
  Codegen marks the operand, and the runtime reuses it when the box has
  one reference and the buffer is not shared.
- The public members lower in MIR to a few private members with an
  operation code and a source position: `__reduce_axis`, `__mean_axis`,
  `__unary`, `__unary_int64`, `__unary_float64`, `__pairwise`,
  `__compare`, `__mask_test`, `__mask_count`, `__choose`, and four
  `__cast_*`. Each has one result type, which the type inference over
  MIR needs.
- The parser accepts `as Array[`. An Array cast reads its operand.
- A mask element read takes the runtime call. The in-place element read
  of native code covers the four numeric dtypes.

Not done in item 2:

- Math members on `float32`.
- The math members call the scalar `libm` functions one element at a
  time. NumPy vectorizes `exp`, `log`, `sin`, and `cos`.
- Arrays are still not iterable with `for`.
