# Aura 0.3.4 preview release

## Goal

Release Aura 0.3.4 as a technical preview on 2026-09-22, with every
user-facing document rewritten in the style now recorded in AGENTS.md.

## Cutoff

The release is cut from `main` at `372ed8e7`, the merge of the Batch 2
phase 2a element and entry loan slice (PR #17). It contains the Batch 1
work (union types, complete callable contracts, the `Option` removal), the
representation phase (inline unions and four-word callables), and element
and entry views.

It does not contain phase 2a item 1, contextual element reads. That work is
saved unverified on `codex/batch-2-phase-2a-2` at `f4c0eedd`: it does not yet
build cleanly, the direct backend crashes on five of its fixtures, and it has
had no coverage or full chain run. It goes into the next preview.

## Work completed

- Removed the tests that gated documentation: the reference check, the Manual
  block manifest and runner, the tutorial fence checker and its workflow, and
  the tests that pinned README, Manual, landing-page, and install-guide
  wording. Tests of code, manifests, workflows, the installer, and packaging
  stay. The owner asked for this so the documentation can change freely.
- Bumped the CLI, compiler, and language server to 0.3.4 and the VS Code
  extension to 0.3.5; the installer names `v0.3.4-preview`.
- Added a documentation style guide to AGENTS.md.
- Rewrote the user-facing documentation in that style: the root and package
  READMEs, the site landing and install pages, the Learn guide, the
  tutorials, the examples index, the benchmark READMEs, and every Manual
  page. ADRs, work notes, the original language proposal, and the ML systems
  plan are historical records and were not rewritten.
- Rewrote the 0.3.4 CHANGELOG section around breaking changes, language,
  performance, tooling, fixes, and current limits.

## Verification

- Local `npm run ci` chain green at `3da266fc` on 2026-09-22. Compiler
  coverage is 96.47% lines, 97.41% functions, and 95.30% regions against
  the unchanged floors of 96.46, 97.33, and 95.23.
- Hosted CI run `35764567940` for PR #18 passed on macOS 15 and Ubuntu 24.04.
- PR #18 merged as `0d517519`, whose tree is identical to `3da266fc`.
- Annotated tag `v0.3.4-preview` on `0d517519`, unsigned because no
  repository signing identity is configured. The tag push did not start the
  Release workflow, so it was dispatched by hand with `publish=true` and
  `publish_extension=true` (run `35780124274`).
- During the rewrite, two script-scope view bugs were found and fixed with
  fixtures: assigning through a top-level view, and a view of an immutable
  top-level binding.

## Follow-up

- `docs/example-check`: compiles every `aura` block in the docs with
  `aura check`, using `fragment` and `check-fail:AUxxxx` fence markers. It
  found and fixed 17 broken examples.
- `lang/script-bindings`: in a script, a bare binding after the first
  top-level statement is an immutable local instead of a module constant.
- Phase 2a item 1 on `codex/batch-2-phase-2a-2`, then the rest of phase 2a.
