# Aura 0.13.0 Preview Release

## Goal

Release Aura 0.13.0 as a technical preview. On 2026-11-08 John approved
cutting it while the lean-values (Python gap) and class-field speed work
continue in their own threads.

## Cutoff

The candidate is cut from `main` @ `d95919d`, after verification V4
(#237). It holds the Batch 8 multicore runtime (#218, #220, #222), Batch 9
generators, iterator sources, and associated types (#219, #223 to #226),
the iterator and generator speed work (#227, #228, #230 to #232), the
first JSON lean-values step (#234), the book's `read_line` fix and match
help line (#236), and verification V2 to V4 (#229, #233, #235, #237).

## Measurements

On the shared Linux x86-64 container with 4 vCPUs, at the bench size, the
published 0.12.0 archive (running the 0.12.0 sources of the programs) and
the candidate were measured in two passes of five runs each, alternating,
and each time is the median of the ten. Python and Rust medians pool all
four runs. Each Aura version also ran once under callgrind. The table for
each program is in `benchmarks/cross_language/README.md`.

| Measure | Aura 0.12.0 | Aura 0.13.0 |
| --- | ---: | ---: |
| All 30 programs, wall time | 14.2 s | 10.0 s |
| Median Aura / Rust | 3.6x | 3.4x |
| Median Aura / Python 3.13 | 0.42x | 0.37x |
| Programs faster than Python | 24 | 25 |
| Programs above 8x Rust | 0 | 0 |
| Instructions, all 30 programs | 88,548M | 78,048M |

The container was much less busy than at the 0.12.0 release (Python 30 s
instead of 46 s). The threaded programs gain most from Batch 8
(`kv_server` -80%, `pubsub_broker` -72%, `task_pool` -59%, `http_api`
-52%), and `docdb` and `json_roundtrip` run 47% and 43% fewer
instructions. `sql_engine` and `spreadsheet` read 18 to 19% slower in the
full passes but 15% and 32% faster in two more alternating passes of five
runs each; `graph_paths` and `lzw_compress` read 4 to 10% slower in both
with 4 to 5% fewer instructions. Linux hello world is 1,076,304 bytes;
0.12.0 builds it at 1,029,184 bytes on the same host.

## Work Completed

- Bumped the CLI, compiler, core, runtime, root package, language server,
  and VS Code extension to 0.13.0. The semantic interface stays 20, and
  the native cache format stays `v10`.
- Updated `Cargo.lock`, the path crates in `fuzz/Cargo.lock`, and
  `package-lock.json`.
- Pointed the installer, release workflow example, install guides, Manual
  stamp, docs release metadata, CLI README, release process page, and book
  at `v0.13.0-preview`, and reframed the maintained pages as Aura 0.13. The
  seeded randomness promise now covers the 0.13.x series. Regenerated
  `llms.txt` and `llms-full.txt`.
- Recorded the results in the cross-language README and the performance
  page.
- Added the missing changelog entries (Batch 8, `str` appends, JSON, match
  help) and moved the Unreleased entries into the 0.13.0 and extension
  0.13.0 sections.
