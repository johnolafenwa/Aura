# Aura 0.4.0 Review Fixes

## Goal

Fix the defects an external review found in the `v0.4.0-preview`
candidate, `53382d17`, before tagging it. John held the tag and asked for
every finding to be fixed, each with a regression test.

## Work Completed

| Finding | Fix | Regression tests |
| --- | --- | --- |
| F01 formatter turns `(lambda a, b: ...)` into a tuple | Reflow and the token guard treat a comma between `lambda` and its `:` as a parameter separator. | `format_tests.rs` cases, CLI `fmt_stdin_keeps_a_parenthesized_lambda_a_lambda` |
| F02 returned span evaluates its origin twice | The caller reborrows the hidden loan the call already took for an element origin. | run-pass `returned_span_origin_once` |
| F03 span reborrow loses its range | `view alias = part` copies the source span's range, including from a `Span[T]` parameter. | run-pass `span_view_reborrow` |
| F04 span endpoints run before the base | `pin_span_base` evaluates the base and its selectors before the endpoints. | run-pass `span_view_evaluation_order` |
| F05 sequence rest lowered as a shared loan | The named rest binding lowers without typed payload views. | run-pass `sequence_rest_beside_type_pattern`, batch4 test |
| F06 generic class pattern matches one specialization | A class pattern over a union matches every specialization; a tested field with differing types reports `AU2040`. | run-pass `class_pattern_generic_union`, check-fail `class_pattern_generic_union_field_types` |
| F07 member access ignores non-`None` narrowing | Member typing reads the narrowed member; MIR projects the union payload. | `union_narrow_*` fixtures, `union_narrowing_members.rs` |
| F08 stale importers in the editor | The server handles watched-file events, keeps analysis dependencies, and sends open buffers as `overlays`. | LSP and extension protocol tests |
| F09 Unicode shifts LSP positions | `positions.js` converts compiler byte offsets to UTF-16 at the protocol boundary. | `positions.test.js`, LSP and extension tests |
| F10 definition selects `def he` | Definition and symbol ranges use the declared name. | analysis tests, LSP test |
| F11 multicursor Enter misplaces cursors | Cursors move down by the number of earlier insertions. | `newline_command.test.js` |

Also fixed:

- A literal index after a returned-view call was always a tuple position.
  `total(rows_of(g)[0][1:])` now runs, and an element view such as
  `view first = rows_of(g)[0]` reports `AU3004` instead of failing at run
  time. Fixtures `span_argument_returned_view_index` and
  `returned_view_element_view`.
- An or-pattern of class patterns with bindings over a union failed MIR
  validation. A narrowed field passed to a `mut T | None` parameter failed
  MIR validation.
- The Pages deploy job now needs the documentation example check.
- Maintained pages framed the release as 0.3. A release-metadata test now
  rejects the previous minor version on maintained pages. The seeded
  randomness promise covers 0.3.x and 0.4.x.
- Main includes the security fixes from PR #49.

## Verification

- Each new test failed before its fix.
- Each fix branch ran its targeted Rust tests, `cargo fmt --check`, and
  `cargo clippy -p aura-compiler -p aura -- -D warnings`.
- All 622 run-pass fixtures matched their expected output on both the MIR
  and direct backends after the span fixes.
- The merged branch results are recorded on the pull request. Hosted CI runs
  the full parity matrix and the coverage gates.

## Follow-Up

- The language server sends every open document as an overlay. Limiting
  overlays to known dependencies would shrink requests.
- `Diagnostic.data` edits still carry byte columns.
- Tests that count live child processes assume PID 1 reaps orphans. A
  container without an init process needs a subreaper.
