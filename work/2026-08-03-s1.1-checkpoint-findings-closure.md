## Equality gating

S1.1-a is implemented at the shared equality-obligation boundary. Callables,
`random.Rng`, opaque FFI handles, and aggregate types containing them are now
rejected before list search, membership, set insertion, dictionary-key use, or
direct equality can reach either backend. The focused fixture family covers
callables and `random.Rng` through `list.remove`, `list.index`, `list.count`,
membership, `set.add`, and dictionary assignment. A forced-backend test pins
byte-identical AU2008 diagnostics for every fixture under MIR and direct mode.

The broader semantic rerun exposed a classification edge: collection
construction with opaque FFI keys or set elements now correctly fails the
equality obligation before a later clone-producing observer can be reached.
The clone-safety test retains only reachable observer cases; direct and
aggregate opaque equality tests now pin AU2008.

The complete run-pass sweep then found the maintained
`random_identity_and_render` fixture still asserting generator identity.
That obsolete surface was removed: `random_render` now pins rendering and
deterministic advancement, while `equality_rng_direct` pins the AU2008
rejection in both forced backends. The randomness and conformance pages no
longer claim public generator identity equality.

## F-string closure

S1.1-b takes the implementation path. A leading zero in a numeric width now
uses sign-aware zero padding, matching Python for `09.3f`; the MIR fixture and
an explicit direct-backend run both produce `-0001.250`, `00001.250`, and
`+0001.250`. Existing `08d` and `04x` tests were restamped to the newly defined
behavior. Raw `rf`/`fr` prefixes and triple-quoted f-string prefixes now stop in
the lexer with focused AU1002 guidance to single-line `f"..."`.

The Manual and ADR-0046 record the shorthand. The Python-comparison note also
records that Aura requires an explicit `d`, `f`, or `%` code for comma
grouping, so Python's `{n:,}` is written `{n:,d}`, `{n:,f}`, or `{n:,%}`.

## Root match bindings

S1.1-c takes the implementation path. The parser, AST, pattern binding,
coverage analysis, MIR decision tree, and direct lowering already represented
root binding patterns; four checker branches were the complete missing gate.
Those branches now bind the complete scrutinee and classify an unguarded root
binding as the final catch-all. A guarded root binding exposes the name to its
condition and body without contributing to exhaustiveness.

The regression covers statement and expression forms plus shared, owned, and
mutable complete-value capabilities. The run-pass fixture is byte-identical
under explicit MIR and direct execution. ADR-0049, the Manual, grammar,
tutorial, example, and conformance ledger now define the accepted form.
