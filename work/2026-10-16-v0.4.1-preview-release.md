# Aura 0.4.1 Preview Release

## Goal

Release Aura 0.4.1 as a technical preview with the fixes from PR #52, as
John asked on 2026-10-15.

## Cutoff

The candidate is cut from `main` at `cb7e3472`, the merge of PR #52. Hosted
CI `38832731601` passed on the PR head `d4a1f16b` on Linux and macOS, and
the documentation build passed.

## Work Completed

- Bumped the CLI, compiler, root package, language server, and VS Code
  extension to 0.4.1. The semantic interface stays 19.
- Updated `Cargo.lock`, the `aura-compiler` entry in `fuzz/Cargo.lock`, and
  `package-lock.json`.
- Pointed the installer, release workflow example, install guides, Manual
  stamp, docs release metadata, CLI README, release process page, and
  tutorial 01 at `v0.4.1-preview`. Regenerated `llms.txt` and
  `llms-full.txt`.
- Moved the Unreleased CHANGELOG entries into the 0.4.1 and extension 0.4.1
  sections.

## Verification

- Local: release metadata and packaging (46), identity, docs release
  metadata (6), language server (136), extension check and tests (37),
  documentation examples (789), hygiene, `docs:llms:check`, and
  `npm audit`. `aura --version` prints `aura 0.4.1-dev`.
- `cargo audit` and the full `npm run ci` chain run on hosted CI for the
  pull request.

## Release

- PR #53 merged as `1665d4d2` after hosted CI `38867459789` passed on
  Linux and macOS.
- The annotated tag `v0.4.1-preview` on `1665d4d2` is unsigned by choice
  because no repository signing identity is configured. It was pushed from
  the owner's checkout after John approved.
- Release `38884366924` passed. It published the GitHub Release with the
  Linux x64, macOS arm64, and macOS x64 archives, the docs archive, the
  VSIX, and `SHA256SUMS`, and published extension 0.4.1 to the Visual
  Studio Marketplace and Open VSX.
