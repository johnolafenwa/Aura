# Exact integers, decimals and complex arithmetic

The numbers module supplies BigInt, Decimal and Complex. On the initial
branch the runtime unit tests failed to compile because two tests used a
nonexistent list constructor. They now explicitly exercise boxed integer
elements alongside the packed uint64 representation. Running the suite
then exposed a formatting bug. A negative Decimal which rounds to zero
renders its sign in fixed-point text, so rounding -0.005 to two places
prints -0.00.

All 21 numbers host tests passed. The compiler crate also completed
`cargo check -p aura-compiler --locked`. Native representation, performance
comparisons and the public documentation remain in progress.

The scalar and limb representations now share a tagged field, with a
scalar coefficient and exponent for small decimals. The compiler layout
and checker tests passed. The 23 runtime kernel tests passed, including
word-sized modular powers at both int64 limits and carry propagation in
borrowed-limb addition. The native entry test passed with aliased operands.

Multiplying or adding complex values uses concrete binary64 operands.
Finite values near the largest float exposed overflow in the intermediate
steps of division and square root. Both failures reproduced and the
corrected calculations passed in an interpreter test. The final fixture
also checks rounding, moving a large value through a task, and using a
number inside a list or optional result.

The comparison programs and public documentation are in the feature
checkout. Whole-program parity, final release timings, and hosted checks
are pending.

A native build exposed a synthetic fallthrough after the two storage tags
in BigInt.copy and Decimal.copy. MIR now ends the unmatched edge of an
exhaustive union match with an unreachable terminator. The benchmark entry
is main.au so it can import the standard numbers module by name.

The unfinished checker change had accepted a scalar-left generic operator
that MIR executed with the wrong type argument. The integration compiler
diagnosed that call with AU2002. Numbers uses the existing operator
contracts and explicit conversion rule, so the checker retains that
behavior. All 159 editor tests passed. All 1095 documentation examples
passed across the first run and a retry of three chapters after a worker
resource spike.
