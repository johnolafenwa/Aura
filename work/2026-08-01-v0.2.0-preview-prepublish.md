# Aurora 0.2.0-preview pre-publish patch

Date: 2026-08-01

## Goal

Close the approved pre-publish blockers, prove the resulting immutable commit
with the maintained full gate, move the local preview tag, rebuild the local
release set, and stop without pushing or publishing.

## Work completed

- Reproduced the Queue receive-iteration livelock at the default worker count
  with iteration consumers, a bounded producer queue, and more CPU burners
  than workers. Explicit `Queue.get()` consumers completed the identical load.
- Isolated the defect to registered-producer iteration retaining completed
  producer tasks in later scheduler waits. A completed task made readiness
  permanently true, so consumers repeatedly entered the wait path instead of
  parking while remaining producers needed worker time.
- Changed that iteration path to subscribe only to producer tasks whose result
  is still pending. This is a contained wake-set correction; it does not alter
  the scheduler, Queue ordering, closure, cancellation, or task-group rules.
- Added a failing-first CLI regression that derives the default worker count,
  launches four more CPU burners, and requires the 1,000-item result on MIR
  and direct without setting `AURORA_WORKERS`.
- Changed CLI version output to
  `aura 0.2.0-preview (<12-hex-commit>)`. A new build script derives the commit
  from Git, watches HEAD and its symbolic ref for rebuilds, accepts a validated
  `AURORA_BUILD_COMMIT` for controlled builds, and refuses an identity-free
  build.
- Updated archive smoke, release workflow input, CLI tests, READMEs, Learn,
  tutorial, Manual, changelog, and conformance text for the preview identity.
- Marked GitHub releases as prereleases. The publish job now sorts downloaded
  artifacts, generates `SHA256SUMS`, verifies it, and attaches the manifest
  with the other release assets.
- Added `gh auth login` and `gh auth status` to the handoff prerequisites.
- Raised the named concurrent cold-cache test's post-barrier budget from 60 to
  120 seconds.
- Replaced backend parity's fixed `target/debug/libaurora_compiler.a` lookup
  with the exact static archive path from Cargo's `compiler-artifact` JSON.
- Retired the last “shared borrowed values” AU3002 wording while keeping the
  diagnostic code explicit and stable.
- Updated the historical proposal disclaimer from the “0.1 contract” to the
  maintained “0.1/0.2 contract” in Markdown and its maintained HTML copy.
- Checked tag-signing configuration. No Git signing key, GPG secret key, or
  SSH-agent identity is configured, so `v0.2.0-preview` is deliberately an
  annotated unsigned tag.
