# Aura 0.3.5 preview release

## Goal

Release Aura 0.3.5 as a technical preview, carrying the completed Batch 2
phase 2a work (element and entry loans) that merged after 0.3.4.

## Cutoff

The release is cut from `main` at `1a3e4174`, the merge of the phase 2a
closeout (PR #28). Hosted CI run `35985124138` is green on that commit. The
release adds no compiler changes beyond `main`.

## Work completed

- Bumped the CLI, compiler, and language server to 0.3.5 and the VS Code
  extension to 0.3.6. The extension bump is needed because the bundled
  language server speaks semantic interface version 17, and 0.3.5 of the
  extension speaks 16. The installer names `v0.3.5-preview`.
- Updated the release-metadata, release-packaging, and extension tests to the
  new versions first, confirmed they failed, then bumped the manifests.
- Moved the CHANGELOG "Unreleased" entries into a 0.3.5 section with
  breaking changes, language, fixes, and current limits, plus an extension
  0.3.6 section.
- Updated version strings in the install, download, Learn, Manual, and
  tutorial pages, and regenerated `docs/public/llms*.txt`.
- Ran `npm audit fix` for advisories published after `main` last passed CI:
  `vue` and `@vue/server-renderer` (GHSA-g2v6-rqmx-r4w6), `brace-expansion`,
  and `source-map-js`. Only `package-lock.json` changed.
- Corrected the Manual pages and the language server README that still named
  semantic schema version 16, and stamped the docs site release metadata
  0.3.5.

## Verification

- Focused local checks: release metadata, release packaging, identity, LSP
  116/116, extension 28/28 and packaging, 733 documentation examples, LLM
  docs check, docs build, format, hygiene, and `cargo audit`.
- The first hosted run failed only at `npm audit`, on advisories published
  after `main` last passed. After the lock refresh, CI `38093579653` passed
  on Ubuntu 24.04 and macOS 15, and Docs `38093579652` passed.
- PR #29 merged as `420ddbef`. Annotated tag `v0.3.5-preview` (`0c9f4ea3`)
  on `420ddbef`, unsigned because no repository signing identity is
  configured. The tag was pushed from the owner's machine.
- The tag push started Release `38125107495`, which succeeded: three CLI
  archives, docs, VSIX, and `SHA256SUMS` on the GitHub Release, and
  `JohnOlafenwa.vscode-aura-lang` 0.3.6 on the Visual Studio Marketplace and
  Open VSX.
