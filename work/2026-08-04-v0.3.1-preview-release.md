# Aura v0.3.1-preview release

## Goal

Prepare and publish Aura v0.3.1-preview as one coordinated compiler, tooling,
documentation, and editor patch release. No new language feature is part of
this release.

## Release inventory

- Workspace crates, npm packages, language server, and VS Code extension:
  `0.3.1`.
- Release identity: annotated tag `v0.3.1-preview`.
- CLI targets: Linux x86-64, macOS x86-64, and macOS Apple silicon.
- Tool artifacts: static documentation archive and
  `JohnOlafenwa.vscode-aura-lang` version `0.3.1`.
- Public installer: `docs/public/install.sh`, pinned to the preview tag and its
  `SHA256SUMS` manifest.
- Publication path: the tag-triggered Release workflow creates the GitHub
  prerelease and publishes the same VSIX to Visual Studio Marketplace and Open
  VSX. Both repository secrets are configured by the user.
- Tag signature: unsigned by choice because this checkout has no configured
  signing identity.

## Included changes

- Plain and compound reassignment of mutable top-level script locals works on
  both backends. Invalid module-constant reads of script locals receive the
  focused initialization-order diagnostic.
- Direct integer equality and inequality preserve `int32` and `uint64`
  function-call return types with MIR/direct parity.
- LSP documentation includes the required `semantic_interface_version: 5`
  request field.
- The VS Code language contribution assigns the maintained Aura mark to `.au`
  files.
- Platform installation guides, native Aura documentation highlighting,
  AI-agent entry points, Learn material, casting, testing, and language
  positioning added since v0.3.0-preview are included.
