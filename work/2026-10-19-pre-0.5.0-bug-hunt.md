# Bug Hunt Before 0.5.0-preview

## Goal

Find and fix bugs in the work merged from v0.4.1-preview (`1665d4d2`) to
`main` at `64642c8` before cutting 0.5.0-preview. John asked for the hunt
and chose to fix every confirmed bug before the release.

## Work Completed

Four review passes covered the Batch 7a collections, thread confinement,
direct-backend field lending and comparison fast paths, Batch 5 pruning, and
the new `fs` APIs. Each finding ran on the current compiler and on a v0.4.1
build, with both backends.

| # | Bug | Fix |
|---|-----|-----|
| R1 | Direct field lending moved `x.items` before `y.items` was read when both name one object. | `lendable_arguments` and `lendable_receiver` skip a field another argument may reach from a different root. |
| R2 | Same hole for a lent element receiver. | Same check. |
| B1 | Nested index assignment `d["a"][0] = 5` dropped the write on direct. | Index assignment lowers its object through an element loan. |
| B2 | `get` and `copy` duplicated a file, process, or socket handle. | The checker rejects a clone-producing operation on a resource with `AU3007`. |
| B3 | A string-key loan ending in both `if` arms panicked direct. | `EndLoan` releases the loan's keys on every path. |
| B4 | Returning a union parameter of Copy members failed MIR validation. | The validator treats a union of Copy members as Copy. |
| B5 | Index assignment through a view or `match mut` binding failed to compile. | The assignment writes through the view's place. |
| B6 | `match mut` over a `view mut` alias failed, and a view write in the arm was lost. | The match writeback ends the loan in both blocks and tracks `WriteLoan`. |
| B7 | `rows[i].sort()` panicked the compiler. | The sort receiver uses an element loan. |
| B8 | A lambda naming `math.cos` captured the module. | Lambdas skip module bindings when collecting captures. |
| B9 | `x = math.nan` reported `AU3001`. | A qualified Copy module constant reads as a copy. |
| B10 | A default argument could not name a module constant or import. | Defaults resolve in their declaring module through a generated helper. |
| B11 | A private imported `Item` in a union clashed with the root `Item` on direct. | Union injections take runtime member names from the expected union. |

R1 and R2 came from PR #60. The other bugs predate 0.4.1. The full list with
repros is in the project file `release-0.5.0/bug-hunt.md`.

## Verification

- Regression tests: `crates/aura/tests/representation_stats.rs`,
  `crates/aura/tests/cli.rs`, `crates/aura-compiler/tests/modules.rs`, and
  new run-pass and check-fail fixtures.
- `cargo test --workspace`, `cargo clippy -D warnings`, and `cargo fmt`
  pass locally. Hosted CI passed on Linux and macOS for PR #78.
