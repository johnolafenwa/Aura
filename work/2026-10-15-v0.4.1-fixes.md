# Aura 0.4.1 Fixes

## Goal

Fix the defects left open after Batch 4 and the shared git cache fallback
from the 0.4.0 security review, as John asked on 2026-10-15, ahead of a
0.4.1 preview release.

## Work Completed

| Defect | Status | Fix | Regression tests |
| --- | --- | --- | --- |
| `x.m() as float64` reports "result type mismatch" | Fixed | A cast passes its target type to the operand only for literal arithmetic. Calls and conditionals keep their own type. | run-pass `cast_call_result` |
| Duplicate or-alternatives of class patterns over a union are not reported | Fixed | Or-patterns over a union scrutinee run the duplicate and subsumption check. | check-fail `or_pattern_duplicate_union_class`, `or_pattern_subsumed_union_class` |
| `geometry.Point \| None` fails at run time with `AU4001` | Fixed | MIR resolves a module-alias type spelling through the canonical type names, so local annotations name the class by its module path. | run-pass `union_module_alias_member` |
| A view local forwarded from a method's returned view fails with `AU4001` | Does not reproduce on `7ba9f7e` | None needed. | run-pass `view_forwarded_method_view` |
| A comprehension over `obj.items()` fails | Does not reproduce on `7ba9f7e` | None needed. | run-pass `comprehension_member_items` |
| `dict.set` type-checks, then MIR lowering fails | Does not reproduce on `7ba9f7e`: the checker rejects it with `AU2001` | None needed. | check-fail `dict_set_is_not_public` |
| The MIR validator may not check enum payload arity | Fixed | `validate_loan_flow` rejects an undeclared variant or a wrong payload count for a module enum. | `loan_validator_rejects_enum_payload_arity_forgery` |
| Shared `$TMPDIR/aura/git` cache fallback | Removed | `git_cache_root` uses `XDG_CACHE_HOME` or `HOME` and errors when neither is set. | `package_io_helpers_cover_local_error_paths` |

The manual's cast and package pages and the CHANGELOG describe the new
behavior.

## Verification

- Each new fixture that covers a fixed defect failed before its fix. The
  three non-reproducing defects pass before and after.
- The `fixtures` integration test passes on the MIR backend.
- `cargo fmt --check` passes.
- Locally, the full Rust suite and forced backend parity pass. Hosted CI
  `38832731601` passed on Linux and macOS.

## Follow-Up

- `t.clone()` on a tuple reports `AU2999` "unsupported method call".
  Tuples are not cloneable today, so the checker could say so with a
  clearer code.
- `crates/aura-compiler/src/mir.rs.orig` is a tracked stray file.
- Still open from Batch 4: the repeated redirect check in the member-call
  candidate loop in `mir.rs`, and the possibly flaky
  `native_runtime_direct_cancellation_releases_frame_owned_argument_references`.
