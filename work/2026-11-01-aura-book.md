# The Aura Programming Language (book)

- Requested by John on 2026-11-01: make the docs read like The Rust
  Programming Language book instead of generic, machine-written prose.
- New book under `docs/book/`: 19 chapters and 5 appendices, laid out like
  the Rust book (`chNN-MM-slug.md`), about 150,000 words. Chapters 2, 12 and
  19 are projects (word counter, log analyzer, supervised job runner).
- Voice guide: `docs/book/STYLE.md`. Outline: `docs/book/OUTLINE.md`. Neither
  is published.
- Written in parallel by eight writers, then three editorial passes for
  voice, cross-chapter consistency and accuracy. Every console block is real
  output from the current compiler; chapter 17 numbers were measured with a
  release build on a Linux x86-64 container.

## Checks

- `scripts/check_doc_examples.py` compiles all 566 book examples
  (check-pass, check-fail with exact codes, fragment).
- `format_tests::every_example_and_tutorial_program_formats_idempotently`
  now also covers `docs/book`.
- `docs/.vitepress/book-sidebar.mjs` builds the sidebar from the file names
  and headings; `npm run test:docs-site` tests it.
- `llms.txt` and `llms-full.txt` include the book in reading order.
