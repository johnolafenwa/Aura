# Aura v0.3.0-preview release

## Goal

Prepare and publish Aura v0.3.0-preview as one coordinated compiler, runtime,
documentation, and editor release. This release adds no language features.

## Release inventory

- Workspace crates, npm packages, language server, and VS Code extension:
  `0.3.0`.
- Release identity: annotated tag `v0.3.0-preview`.
- CLI targets: Linux x86-64, macOS x86-64, and macOS Apple silicon.
- Tool artifacts: static documentation archive and
  `JohnOlafenwa.vscode-aura-lang` version `0.3.0`.
- Public installer: `docs/public/install.sh`, pinned to the preview tag and its
  `SHA256SUMS` manifest.
- Publication path: the tag-triggered Release workflow creates the GitHub
  prerelease and sends the same VSIX to Visual Studio Marketplace and Open
  VSX. Both repository secrets are configured by the user.
- Tag signature: unsigned by choice because this checkout has no configured
  GPG or SSH signing identity.
