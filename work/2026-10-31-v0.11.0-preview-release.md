# Aura 0.11.0 Preview Release

## Goal

Release Aura 0.11.0 as a technical preview. On 2026-10-31 John chose to
release after the beat-Python steps, then asked for the sequence builtins
and the VS Code debugger to land before the release.

## Cutoff

The candidate is cut from `main` after the debugger (#205). It holds the
cheaper blocking-pool hand-off (#198), beat-Python steps 1a to 4a (#199 to
#203), the sequence builtins (#204, ADR-0066), and `aura build --debug`
with the VS Code debugger (#205, ADR-0067).

## Measurements

On the shared Linux x86-64 container with 4 vCPUs, at the bench size, the
published 0.10.0 archive and the candidate were measured in two passes of
five runs each, alternating, and each time is the median of the ten.
Python and Rust medians pool all four runs. The table for each program is
in `benchmarks/cross_language/README.md`.

| Measure | Aura 0.10.0 | Aura 0.11.0 |
| --- | ---: | ---: |
| All 30 programs, wall time | 17.9 s | 16.4 s |
| Median Aura / Rust | 3.9x | 3.7x |
| Median Aura / Python 3.13 | 0.41x | 0.40x |
| Programs faster than Python | 25 | 25 |
| Programs above 8x Rust | 0 | 0 |

The container ran faster than on 2026-10-30: 0.10.0 measured 17.9 s here
against 20.9 s at its release. Largest gains: `file_io` -36% (2.4x ->
1.5x Rust), `docdb` -26%, `json_roundtrip` -21%, `template_render` -18%,
`raytracer` -14%, `regex_match` -11% (7.4x -> 6.5x). Furthest from Rust:
`sql_engine` 7.6x, `regex_match` 6.5x, `lzw_compress` 6.3x. Still slower
than Python: `csv_aggregate` 1.21x, `docdb` 2.36x, `file_io` 1.20x,
`json_roundtrip` 1.55x, `template_render` 1.48x. `interpreter` (+11%),
`image_filters`, `astar_pathfinding` (+9%), and `kv_server` (+8%) read
slower; run alone again, `interpreter` and `csv_aggregate` came within 4%
of 0.10.0, inside their run-to-run spread.

  and VS Code extension to 0.11.0. The semantic interface stays 20, and
  the native cache format stays `v10`.
- Updated `Cargo.lock`, the path crates in `fuzz/Cargo.lock`, and
  `package-lock.json`.
- Pointed the installer, release workflow example, install guides, Manual
  stamp, docs release metadata, CLI README, release process page, and
  tutorials at `v0.11.0-preview`, and reframed the maintained pages as
  Aura 0.11. The seeded randomness promise now covers the 0.11.x series.
  Regenerated `llms.txt` and `llms-full.txt`.
- Recorded the results in the cross-language README and the performance
  page.
- Moved the Unreleased CHANGELOG entries into the 0.11.0 and extension
  0.11.0 sections.
