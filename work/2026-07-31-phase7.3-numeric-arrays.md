# Phase 7.3: Contiguous Numeric Arrays

## Goal

Land the accepted Aurora 0.2 `Array[T]` surface for the exact maintained
`int32`, `int64`, `float32`, and `float64` dtypes, together with explicit
wrapping and saturating integer arithmetic modes, both execution backends,
editor intelligence, documentation, examples, and reproducible release
evidence.

## Work Completed

- Accepted ADR-0041 as the binding dtype, shape, ownership, arithmetic,
  reduction, indexing, slicing, diagnostic, and backend contract.
- Added the normative Numeric Arrays Manual chapter and synchronized grammar,
  types, static semantics, expressions, execution, diagnostics, conformance,
  API index, current limits, compatibility status, Learn, tutorials, CLI,
  editor, changelog, and ML-systems planning material.
- Added `examples/numbers/numeric_arrays.au` and linked it from the maintained
  example inventories and tutorials.
- Added compiler-backed language-server and bundled-extension protocol
  regressions for Array completion, hover, result types, and diagnostics.
- Added a tested `float64` add/sum benchmark protocol against NumPy. The
  harness builds standalone direct-backend workloads, owns every measured
  process group, alternates paired order, pins a single-thread environment,
  validates checksums, retains raw samples and provenance, and writes an
  SHA-256-linked summary without an Aurora-versus-NumPy performance gate.
- Added source-hash-pinned executable Manual metadata and reference-integrity
  guards for the maintained Phase 7.3 surface.
- Closed independent audit findings: shared MIR operations no longer
  deep-copy Array storage; explicit and recursively nested Array copies are
  fallible; `from_vec` validates shape/count before allocation; equality is
  recursively unavailable through containers, membership, keys, generic
  functions, methods, and trait dispatch; and all four dtypes plus invalid
  shape parity are covered by the native and forced-backend matrices.
- Completed benchmark evidence hardening: the process helper is included in
  the input hash record, and contractual evidence requires two quiet-host
  snapshots that reject repository builds and sustained high-CPU competitors.
