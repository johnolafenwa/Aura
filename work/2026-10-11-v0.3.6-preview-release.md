# Aura 0.3.6 preview release

## Goal

Release Aura 0.3.6 as a technical preview carrying the fixes for the
external 0.3.5 review. John asked for the fixes to be merged and released.

## Cutoff

The release ships from the merge of the review-fix pull request (PR #31),
which carries both the fixes and this release preparation. The fixes are
described in `2026-10-11-v0.3.5-review-fixes.md`.

## Work Completed

- Bumped the CLI, compiler, and language server to 0.3.6 and the VS Code
  extension to 0.3.7. The extension bump is needed because the release
  workflow publishes the extension on every tag, and 0.3.6 is already
  published. The semantic interface version stays 17.
- Moved the CHANGELOG fixes into a 0.3.6 section plus an extension 0.3.7
  section.
- Updated version strings in the install, download, Learn, Manual, and
  tutorial pages, the release tests, and both lockfiles, and regenerated
  `docs/public/llms*.txt`.

## Verification

- Local: `cargo test --workspace`, clippy with `-D warnings`, format,
  release metadata, release packaging, identity, LSP 116/116, extension
  28/28, 733 documentation examples, and `npm audit`.
- Hosted CI on PR #31, the merge, the tag, and the Release run are recorded
  on the task board when they complete.

## Follow-Up

- Push the annotated `v0.3.6-preview` tag on the merge commit. Cloud
  sessions cannot push tags, so the owner pushes it.
