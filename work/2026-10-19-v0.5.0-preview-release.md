# Aura 0.5.0 Preview Release

## Goal

Release Aura 0.5.0 as a technical preview with Batch 5, Batch 7a, and the
pre-release bug hunt fixes. John chose to release before starting Batch 6
on 2026-10-19, and asked for a bug hunt first.

## Cutoff

The candidate is cut from `main` at `b5d82fa2`, the merge of PR #78. Hosted
CI passed on the PR head `15352e63` on Linux and macOS, with the native
binary gates and the documentation examples.

## Work Completed

- Bumped the CLI, compiler, core, runtime, root package, language server,
  and VS Code extension to 0.5.0. The semantic interface stays 19.
- Updated `Cargo.lock`, the `aura-compiler` entry in `fuzz/Cargo.lock`, and
  `package-lock.json`.
- Pointed the installer, release workflow example, install guides, Manual
  stamp, docs release metadata, CLI README, release process page, and
  tutorial 01 at `v0.5.0-preview`. Regenerated `llms.txt` and
  `llms-full.txt`.
- Moved maintained pages from "Aura 0.4" to "Aura 0.5". The seeded random
  stability promise covers 0.5.x, because the algorithm did not change.
  The clone-safety glossary entry names live resources.
- Moved the Unreleased CHANGELOG entries into the 0.5.0 and extension 0.5.0
  sections, with breaking changes, performance, library, and fixes.
