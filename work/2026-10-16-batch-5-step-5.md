# 2026-10-16 Batch 5 Step 5: Reachable Functions and Type Descriptors

## Goal

Generate code only for functions a program can reach, and stop linking
`serde_json` into programs that never use JSON, per sections B4 and B5 of
the [Batch 5 design checkpoint](../architecture_docs/19-batch-5-design-checkpoint.md).

## Work Completed

- Types cross to the runtime as `aura-type-v2:` text descriptors.
  `aura_core::type_descriptor` encodes and decodes them. Structural types,
  function signatures, and FFI union metadata all use them.
- Union canonical keys and structured diagnostics use a small JSON writer in
  `aura_core::json_text`. Tests check its output matches `serde_json` byte
  for byte, so cached keys and diagnostic JSON are unchanged.
- Native codegen first drops builtin module wrappers, such as
  `toml::is_valid`, that no program function reaches. Every function from
  the program itself is still compiled, so codegen keeps validating and
  diagnosing code the program never calls. The walk is conservative: any
  string inside a kept function that names a wrapper keeps that wrapper,
  which covers function values and parameter defaults.
- A first version pruned unreachable program functions too. It broke codegen
  validation tests for uncalled functions and dropped the generated display
  wrappers that the runtime finds by name, so it was narrowed to builtin
  wrappers.

## Sizes

Linux x86-64 release executables after step 4 and after this step:

| Program | Step 4 | Step 5 |
| --- | --- | --- |
| hello world | 945,320 | 927,776 |
| reference agent | 1,687,680 | 1,520,248 |
| JSON | 1,488,200 | 1,364,848 |
| TLS | 3,434,592 | 3,258,720 |
| WebSocket | 3,736,032 | 3,556,360 |

Almost all of the change comes from type descriptors. Reachability saves
about 4 KB per executable, because the linker already dropped unused
generated functions. Its larger effect is on the object file: hello world's
generated object drops from 110 functions and 172,448 bytes to one function
and 21,840 bytes, and the JSON example's from 184,784 to 41,208 bytes.

The contents gate now requires hello world, the agent, the TLS example, and
the WebSocket example to be free of `serde_json`. The Linux baselines are
lowered to the new sizes.

## Verification

- `type_descriptor_tests` round-trips a corpus of types and rejects
  malformed descriptors. `canonical_key` matches the old `serde_json`
  implementation on the same corpus.
- `StructuredDiagnostic::to_json` matches `serde_json` output byte for byte.
- `direct_object_emits_only_the_builtin_wrappers_the_program_reaches`
  failed until codegen skipped uncalled builtin wrappers. It also checks that
  an uncalled program function is still compiled.
- `reachability_keeps_builtin_wrappers_named_by_function_values` checks a
  builtin used as a function value.
- The contents gate passes on Linux with the new baselines.
- The full Rust suite runs one target at a time with `RUST_MIN_STACK` set.
