# 2026-10-16 Batch 5 Step 0: Baseline And Gates

## Goal

Land step 0 of the ratified
[Batch 5 design checkpoint](../architecture_docs/19-batch-5-design-checkpoint.md):
contents and size gates recorded against today's executables, the
dependency feature trim, and removal of the stray `mir.rs.orig`.

## Work Completed

- `rustls` uses `default-features = false` with `logging`, `ring`, `std`,
  and `tls12`. `tungstenite` 0.24 turned `rustls` default features back on,
  so it moves to 0.25, which disables them. `aws-lc-rs` and `aws-lc-sys`
  leave `Cargo.lock`.
- The `tungstenite` 0.25 API change touches only the WebSocket config
  builder and message payload conversions. Every limit keeps its value:
  128 KiB read and write buffers, the maximum write buffer, message and
  frame limits, and masked frames required.
- `scripts/check-native-binaries.py` and
  `benchmarks/native_binaries/contents.json` define five subjects, their
  absent and present components, and per-platform size baselines with a 10%
  budget. A `native-binaries` CI job runs the check on Linux and macOS
  against a release build. `npm run ci` runs the script's unit tests.
- Removed the tracked 1,001,545-byte `crates/aura-compiler/src/mir.rs.orig`.
- Native codegen emits one object section per generated function. Before
  this, all about 110 builtin-module wrappers shared one `.text` section, so
  GNU ld `--gc-sections` kept every runtime function they referenced.
  `rust-lld --why-live` traced hello world's link to TOML, HTTP, and the
  MIR interpreter through `aura_fn_bytes__base64_decode` and
  `aura_direct_host_builtin`. macOS was not affected because `ld64` strips
  per symbol.

Linux x86-64 sizes, after the dependency trim and after one section per
function:

| Subject | Trim only | Per-function sections |
| --- | ---: | ---: |
| `hello_world` | 5,060,568 | 1,034,040 |
| `reference_agent` | 5,383,504 | 3,174,656 |
| `json` | 5,106,864 | 2,560,288 |
| `tls` | 5,493,144 | 3,602,824 |
| `websocket` | 5,382,184 | 3,798,424 |

Hello world no longer links the builtin registry, the MIR interpreter,
TOML, HTTP, `httparse`, or URL code, and the gate makes those absent. Its
`known_present` list keeps `libffi`, `rustls`, `ring`, `tungstenite`, and
`serde_json`, which later steps remove.
