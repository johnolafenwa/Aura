# Aura 0.12.0 Preview Release

## Goal

Release Aura 0.12.0 as a technical preview. On 2026-11-03 John asked to cut
the release before the generator (Batch 9c onward) and multicore (Batch 8)
work continues.

## Cutoff

The candidate is cut from `main` after the `TaskGroup` change (#216). It
holds `ord`, `chr`, `str.chars()` and `min`/`max` of strings (#208,
ADR-0068), runtime contracts (verification V1) and `for` over user
iterators (#211, Batch 9b), the book (#209, #210), the compiler fixes found
while writing it (#212), and the approved language-design changes: range
step, `enumerate` start, `eprint`, `\r` (#213), the builtin prelude (#214,
ADR-0069), unused `Result` as `AU2018` with `_ = expr` (#215, ADR-0070),
and `TaskGroup` only as a `with` item with fail-fast cancellation (#216,
ADR-0071).

## Measurements

On the shared Linux x86-64 container with 4 vCPUs, at the bench size, the
published 0.11.0 archive (running the 0.11.0 sources of the programs) and
the candidate were measured in two passes of five runs each, alternating,
and each time is the median of the ten. Python and Rust medians pool all
four runs. Each Aura version also ran once under callgrind. The table for
each program is in `benchmarks/cross_language/README.md`.

| Measure | Aura 0.11.0 | Aura 0.12.0 |
| --- | ---: | ---: |
| All 30 programs, wall time | 19.7 s | 19.9 s |
| Median Aura / Rust | 3.7x | 3.8x |
| Median Aura / Python 3.13 | 0.45x | 0.46x |
| Programs faster than Python | 24 | 24 |
| Programs above 8x Rust | 0 | 0 |
| Instructions, all 30 programs | 88,387M | 88,341M |

This release has no performance work, and the instruction counts agree:
every program is within 0.1% of 0.11.0 except `task_pool` (1.6% fewer).
The container was busier than at the 0.11.0 release (Python 46 s instead of
41 s), and single programs moved by up to 50% between passes. `nbody` read
52% slower pooled; timed alone, 20 alternating runs pinned to one core, the
0.11.0 and 0.12.0 binaries took 128 and 124 ms, and their MIR is identical.
Linux hello world is 1,029,184 bytes (0.11.0 builds it at 1,020,400 on the
same host); the prelude and new builtins account for the 8.6 KB.
