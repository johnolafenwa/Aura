# 2026-10-17 Batch 5 Step 6: Final Measurements

## Goal

Record the final Batch 5 executable sizes on Linux x86-64 and macOS arm64
from one commit, and update the Performance chapter, the roadmap, and the
task board, per section F of the
[Batch 5 design checkpoint](../architecture_docs/19-batch-5-design-checkpoint.md).

## Work Completed

- Measured every `native-binaries` subject at `bdf9265`, the merge of step
  5. Linux numbers come from a clean `scripts/bench-binary-size.py` run and
  a release build of the same tree. macOS numbers come from the
  `native-binaries` CI job on `795adf8`, the step 5 pull request head, whose
  tree is identical to `bdf9265`.
- Rewrote the Executable Size section of `docs/manual/performance.md` with
  both platforms, the compiler and runtime archive sizes, and which
  libraries each subject links.
- Moved the macOS baselines in `benchmarks/native_binaries/contents.json`
  to the measured sizes. They still held the step 0 numbers, so the 10%
  budget let the macOS agent grow by about 1.5 MB without failing.
- Updated the roadmap row, the CLI chapter's hello world size, the task
  board, and an outcome note in the design checkpoint.

  clean checkout, ran hello world and the agent with Cargo unavailable, and
  matched their pinned output. The report is
  `2026-10-17-batch-5-step-6/executable-sizes-linux.json`.
- `scripts/check-native-binaries.py` passed on Linux against the release
  build, and its `--attribute` mode gave the symbol bytes above.
