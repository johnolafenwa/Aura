# Aura 0.4.0 preview release

## Goal

Release Aura 0.4.0 as a technical preview. It ships Batches 2, 3, and 4,
which merged to `main` after `v0.3.6-preview`. John asked to finish the
phase and release a new version.

## Cutoff

The candidate is cut from `main` at `6f83b0ea`, the merge of the Batch 3
task board update (PR #47). It contains PRs #32 through #47: union
borrowing, `Span[T]` slice views and returned range views, class
initializers, typed context managers, every Batch 4 family, the ownership
fixes, and the dead-code removal. Main CI run `38453498869` is green on
`ab6848cb`; PR #47 changed only work notes.

## Work Completed

- Bumped the CLI, compiler, root package, and language server to 0.4.0 and
  the VS Code extension to 0.4.0. The minor version marks the breaking
  changes: semantic interface 19, the reserved `Span` name, initializer
  construction, `with` shape rules, literal moves, and the formatter's new
  layout.
- Updated `Cargo.lock`, `fuzz/Cargo.lock`, and `package-lock.json`.
- Pointed the installer, release workflow example, install guides, Manual
  stamp, docs release metadata, CLI README, release process page, and
  tutorial 01 at `v0.4.0-preview`. Regenerated `llms.txt` and
  `llms-full.txt`.
- Corrected stale semantic interface `16` and `17` references to `19` in
  the CLI README, the language server README, the Manual CLI page, the
  diagnostics page, and the status page, and the native cache format `v5`
  to `v6`. A new release-metadata test keeps these in step with
  `SEMANTIC_INTERFACE_SCHEMA_VERSION` and `NATIVE_CACHE_FORMAT`.
- Wrote the 0.4.0 and extension 0.4.0 CHANGELOG sections from the work
  notes and PR history. A reviewer checked the breaking changes, new
  diagnostics, and known defects against a build of the candidate.

## Verification

- The release metadata, packaging, docs metadata, and extension tests were
  updated first and failed on the old versions. The new schema test failed
  on the stale pages. All pass after the bump.
- Local: release metadata and packaging (31), docs release metadata,
  language server tests (122), extension tests (30), `cargo fmt --check`,
  `npm run check:hygiene`, and `npm run check:doc-examples` (786
  examples). `aura --version` prints `aura 0.4.0-dev`.
- The full `npm run ci` chain with coverage runs on hosted CI for the PR.
