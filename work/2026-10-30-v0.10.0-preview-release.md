# Aura 0.10.0 Preview Release

## Goal

Release Aura 0.10.0 as a technical preview after phase 5 of the plan to
bring Aura to Rust speed on the 30 cross-language programs. On 2026-10-29
John approved the phase with all its defaults: the release after it is
0.10.0-preview, with Linux timings only, and missed gates are reported here
instead of blocking it.

## Cutoff

The candidate is cut from `main` after step 5i. It holds steps 5a to 5g
(#188 to #194) and 5i (#195), which John asked to include on 2026-10-30
after asking why `sql_engine` was slow.

## Measurements

On the shared Linux x86-64 container with 4 vCPUs, at the bench size, the
0.9.0 compiler and the 5i head were measured in two passes of five runs
each, and each time is the median of the ten. The container was noisy:
programs 5i does not change moved by 20 to 40% between passes, so the
pooled median is used. The table for each program is in
`benchmarks/cross_language/README.md`.

| Measure | Aura 0.9.0 | Aura 0.10.0 |
| --- | ---: | ---: |
| All 30 programs, wall time | 26.1 s | 20.9 s |
| Median Aura / Rust | 4.6x | 3.9x |
| Median Aura / Python 3.13 | 0.50x | 0.40x |
| Programs faster than Python | 22 | 25 |
| Programs above 8x Rust | 4 | 1 |

Closest to Rust: `http_api` 1.0x, `kv_server` 1.2x, `hashing` and
`image_filters` 1.3x, `pubsub_broker` 1.4x. Furthest: `regex_match` 8.6x,
`nbody` and `lzw_compress` 6.3x, `json_roundtrip` 6.2x. Largest gains over
0.9.0: `sql_engine` -73%, `graph_paths` -63%, `binary_trees` -60%,
`mini_browser` -38%, `spreadsheet` -37%, `template_render` -32%,
`bank_ledger` -30%. `bytecode_vm`, `nbody`, and `order_book` read 19 to
30% slower, within their run-to-run spread; their callgrind counts at the
5i head are within 0.3% of 5g's.

## Work Completed

- Bumped the CLI, compiler, core, runtime, root package, language server,
  and VS Code extension to 0.10.0. The semantic interface stays 20, and
  the native cache format stays `v10`.
- Updated `Cargo.lock` with `cargo update --workspace`, the path crates in
  `fuzz/Cargo.lock`, and `package-lock.json` with
  `npm install --package-lock-only`.
- Pointed the installer, release workflow example, install guides, Manual
  stamp, docs release metadata, CLI README, release process page, and
  tutorials at `v0.10.0-preview`, and reframed the maintained pages as
  Aura 0.10. The seeded randomness promise now covers the 0.10.x series.
  Regenerated `llms.txt` and `llms-full.txt`.
- Recorded the results in the cross-language README and the performance
  page.
- Moved the Unreleased CHANGELOG entries into the 0.10.0 and extension
  0.10.0 sections.
