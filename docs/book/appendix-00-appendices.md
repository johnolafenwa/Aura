# Appendices

The appendices are reference material, meant for looking things up rather
than reading straight through. Each one gathers in one place something the
main chapters introduced a piece at a time.

[Appendix A](/book/appendix-01-keywords) lists Aura's reserved keywords and
the contextual words that only mean something in a particular position, so
you can tell at a glance why the parser rejected a name.
[Appendix B](/book/appendix-02-operators) covers the operators, their
precedence, and the punctuation that carries meaning in Aura's syntax.

[Appendix C](/book/appendix-03-from-python) is a guide to Aura for Python
programmers: the habits that carry over unchanged, the ones that do not, and
the reason behind each difference. If you are introducing a Python colleague
to Aura, it is the page to send them.

[Appendix D](/book/appendix-04-tools) tours the tools around the compiler: the
formatter, the test runner, the documentation generator, and the VS Code
extension with its language server and debugger.
[Appendix E](/book/appendix-05-common-diagnostics) walks through the
diagnostics you are most likely to meet while learning, each with a small
program that triggers it and the usual fix.

The [Manual](/manual/) remains the complete reference. When an appendix
simplifies a rule, it links to the Manual page that has the full contract.
